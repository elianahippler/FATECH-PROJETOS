# FATECH-PROJETOS

Sites criados por **Eliana Cristina Hippler da Silva**, estudante do Colégio
Estadual Mendes Gonçalves (Guaíra-PR), para a **FATECH — Feira de
Administração e Tecnologia Mercadológica**. As turmas de Administração
utilizaram os sites para realizar as vendas no dia da feira.

Todas as lojas de pedidos (`fatech*`, `feira*`) seguem o mesmo molde: uma
página de boas-vindas com o botão **"Pedir"**, carrinho e finalização de
pedido — o que muda de uma edição pra outra é o cardápio e a identidade
visual, ajustados conforme a turma que usava o site naquela feira.
